Git Tools — Design drafts

Static HTML mockups serving as the visual spec for the Tauri + React 19 + shadcn/ui implementation.

History
IDEA-style commit list with DAG, branch / tag / HEAD chips, filter bar, and right-side commit details panel showing changed files and message.
history.html
Diff
Side-by-side / Unified / Folded modes, syntax + word-level highlighting, hunk navigation, and a left tree of changed files grouped by directory.
diff.html
Merge
Three-pane conflict editor (LEFT ours / RESULT / RIGHT theirs), conflict navigation, Accept Left/Right/Both, progress bar, and keyboard shortcuts.
merge.html

These pages reuse the same design tokens as src/styles/globals.css, so the React port is a 1:1 visual mapping. Open any of them directly in a browser, or run bunx serve design from the project root for a quick local preview.
